# 🌍 Seismic Data Analysis with Streamlit

An interactive and advanced web application built using Streamlit to perform seismic waveform analysis, frequency domain studies, statistical summaries, peak ground motion calculations, pattern recognition, and event classification.

---

## 📊 Features

- ✅ Data preview with summary statistics and correlation heatmap
- ✅ Waveform visualization in time domain
- ✅ Frequency spectrum and power spectral density analysis (FFT, Welch)
- ✅ Spectrogram and phase angle analysis
- ✅ Peak Ground Acceleration (PGA) and Peak Ground Velocity (PGV) comparison
- ✅ Statistical analysis (Mean, Std, Skewness, Kurtosis)
- ✅ Unsupervised clustering with KMeans + PCA visualization
- ✅ Event classification based on parameters like ML, Mw, Ms, Depth

---

## 🛠️ Technologies Used

- Python
- Streamlit
- Plotly
- NumPy, Pandas, Scipy, Seaborn, Matplotlib
- Scikit-learn
